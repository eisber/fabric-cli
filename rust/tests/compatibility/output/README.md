# Independent output oracle

`cases.json` contains newly hand-authored, synthetic cases; Microsoft MIT
attribution applies. No prior workspace/items/http fixture is modified.
The source pin is `cf67fd52ea8b47e24c725e73d792de6f4a08e2e4`.
`reference.py` verifies whole-file Git blob hashes, then executes complete actual
source definitions with controlled imports and private collaborators.
It does not reimplement output algorithms or use Rust as expected output.

The source constructors, `dumps`, success/error UI JSON helpers, `_safe_print`,
error decorator and main error/interrupt handlers run. A per-case frozen
datetime returns the fixture's injected timestamp; a fake config always selects
JSON. A headless questionary collaborator prints to private LF StringIO streams.
Imports are restricted in a private builtins dictionary; there is no global
module patch, ambient environment/time lookup, auth/network, subprocess, sleep
or file write. Only repository source, fixtures and optional Rust observations
are read. No third-party Python dependencies are required.

From `rust/`, **under a named parent build grant on shared hosts**:

```text
python -B tests\compatibility\output\reference.py
python -B -m unittest discover -s tests\compatibility\output
cargo test --offline --locked -p fabric-cli-output -- --test-threads=1
cargo run --offline --locked -q -p fabric-cli-output --example compatibility_probe
```

Save the probe stdout as UTF-8 to a caller-owned session artifact, then pass that
path to `reference.py --observed <artifact>`. Probe values are actual Rust
public-API outputs. The oracle independently executes the source and compares all
semantic trees **and exact output bytes**, including stdout/stderr, exit, newline,
key order, unknown nested data and omission. Four cases additionally pin
hand-authored literal bytes for indentation 0, 2, 4/Unicode and a decimal midpoint. Expected output is
never generated by the Rust implementation or refreshed to make a test pass.

`test_reference.py` checks source-only behavior and countermeasures: mutations of
result/message/code, key presence, output stream, exit and LF/CRLF are rejected.
Isolated namespace/stream tests guard against process-global mutation. Source
unsupported objects and non-JSON NaN/bytes semantics remain explicit differences.
Writer failures run in standalone Rust consumer tests, including partial writes
without a stderr fallback. See the [bounded matrix](../../../docs/output-compatibility.md)
for source guarantees versus unsupported runtime/terminal behaviors.
